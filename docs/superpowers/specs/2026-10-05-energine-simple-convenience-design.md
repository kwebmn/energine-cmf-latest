# Energine Simple — удобная и чистая система: дизайн

Дата: 2026-10-05. Статус: утверждено пользователем («по очереди в инлайн режиме»).

## 1. Цель

Система, с которой удобно работать разработчику визиток и владельцу сайта; ядро проще и чище. Источники — аудит кода
Energine Simple и разбор xsight (более ранняя CMS той же группы, /var/www/clients/client1/web94, только идеи —
код 2006–2008 годов не переносится).

## 2. Этапы (по очереди, у каждого свой план)

1. **Чистка без риска.**
   - неиспользуемые константы перевода (~500 из 854; FIELD_* — сверка с колонками таблиц);
   - лишнее в шаблоне конфига: `project`, `useTimer`, `asXML`, образец `site.vars`, восемь размеров превью старых тем;
   - `DBWorker::__call` — исключение вместо тихого `false`;
   - мелкие прослойки с одним вызовом — в вызывающий код.
2. **Удобство разработчика.**
   - короткие имена компонентов в XML страниц (`class="TextBlock"`);
   - номер секции по её имени;
   - переводы шаблона файлом рядом с шаблоном, ставятся установщиком;
   - генератор новой страницы одной командой;
   - в отладке — предупреждения о пропущенных константах и ошибках описания полей;
   - один флаг отладки;
   - на странице ошибки — компонент и состояние.
3. **Удобство владельца (идеи xsight).**
   - битые ссылки: `setup checklinks` и список в админке — внутренние ссылки и файлы, без HTTP-проверки внешних;
   - справка «?» у форм админки;
   - новая страница из шаблона сразу с примером текста.
4. **Крупное (по желанию).**
   - конфиги компонентов без копий — наследование;
   - два класса вывода вместо девяти построителей;
   - SQL с параметрами.

Не берём из xsight: файлы в базе, многоступенчатое согласование с ролями, свой поисковый движок, магазин и форум.

## 3. Ограничения

Те же, что раньше: конфиги веб-сервера не трогаются; владелец `web97:client1`; пароли не в git и не в выводе;
письма только локально; web93 только читается; `rebuild.sh` не запускается. Поведение сайта и админки меняется
только там, где этап это называет; сверка шаблонов — `tests/tools/xslt-golden.sh`, полный прогон после каждой задачи.
