# Energine Simple — поиск по сайту

Дата: 2026-10-06. Основание: анализ ядра xSight2 — у Energine Simple поиска нет совсем (страница search убрана на
этапе 1, `sql/cut/stage1.sql`), у xSight был индексатор с весами полей, отсечением окончаний, учётом прав и журналом
запросов; его код брать нельзя (ошибки разбора, N+1, нет сниппетов), идеи — да. Пользователь ответил «сделай» на
порядок: исправления надёжности 6, затем поиск отдельным этапом со своей спецификацией.

## Цель

Посетитель ищет по сайту на своём языке и находит страницы по любой форме слова; владелец видит, что искали и не
нашли. Без внешних сервисов и без новых зависимостей: полнотекстовый индекс MariaDB и своё отсечение окончаний.

## Что видит посетитель

- В шапке сайта — поле «Поиск по сайту» (форма GET на страницу `/search/` своего языка, параметр `q`).
- Страница результатов `/search/?q=…`: запрос в поле, «Найдено: N», список — название страницы ссылкой, отрывок
  текста с найденными словами, выделенными `<mark>`; по 10 на страницу, листалка `&page=N`. Пустой запрос — только
  поле и подсказка; ничего не найдено — текст с советом (другие слова, меньше слов).
- Ищутся все слова запроса в любой форме: «услуги» находит «услуга», «услугами»; «цены» — «цена». Короче трёх букв
  и знаки (`+ - * " ( ) < > ~ @`) не мешают: служебные знаки убираются, короткие слова не обязательны.
- Порядок: совпадение в названии страницы выше, чем в тексте; при равенстве — где слова встречаются чаще.
- В результатах только страницы, которые посетитель может открыть на этом языке: закрытые ему, выключенные на языке,
  служебные (вход, регистрация, админка, карта, robots, sitemap, сама страница поиска) и страницы-ссылки — нет.

## Что видит владелец

- Индекс обновляется сам: при сохранении текста на странице (и откате из истории), при сохранении страницы в
  структуре (название, описание); удаление страницы уносит её из индекса.
- «Административная часть → Поиск по сайту»: что искали, сколько раз, сколько нашлось, когда последний раз; сначала —
  запросы без результатов (подсказка, каких страниц или слов не хватает).
- `setup reindex` — полная переиндексация (после установки, переноса, правки шаблонов); `setup check` — строка о
  числе страниц в индексе.

## Устройство

- Таблица `share_search_index` (smap_id, lang_id — первичный ключ; title, body — текст для отрывка; title_stems,
  body_stems — основы слов; FULLTEXT по title_stems, по body_stems и по обоим; внешний ключ на страницу с каскадом).
- Таблица `share_search_log` (запрос в нижнем регистре + язык — ключ; число поисков, число найденного в последний
  раз, время последнего).
- Гир `SearchIndex`: текст страницы на языке — название, заголовок, описание и все её текстовые блоки (общие блоки
  без страницы не индексируются); HTML → текст (блоки через пробелы, сущности раскрыты); основы слов
  (`Stemmer::stem` — ё→е, нижний регистр, отсечение окончаний ru/ua/en по спискам в коде, основа не короче 3 букв);
  `page(int $smapId)`, `all()`.
- Гир `SiteSearch`: запрос → основы → кандидаты из FULLTEXT (BOOLEAN MODE, префиксы основ), до 200; в PHP — все
  обязательные основы есть, видимость по дереву посетителя (`E()->getMap()`, права), порядок по весу (название ×3);
  отрывок ~200 знаков вокруг первого совпадения, слова в `<mark>` (текст экранирован).
- Компонент `SearchResults` (страница search, шаблон `search.content.xml`) и `SearchLog` (админка, права 3); поле в
  шапке — тема (`energine.xslt`); страницы search и admin/search — данные установки (`sql/cut/stage20.sql`, служебный
  сегмент `search` в `DivisionEditor::SYSTEM_SEGMENTS` и в `tests/tools/regen-sql.sh`).
- Бюджет запросов страницы результатов — как у гостя (не больше 20).

## Не входит

Поиск по файлам (PDF, DOC), подсказки при наборе, исправление опечаток, синонимы, поиск по нескольким языкам сразу.

`tests/search.php` (индекс, основы, поиск, видимость, отрывок, журнал, бюджет запросов, `setup reindex`),
`tests/audit/public.js` (поле в шапке, страница результатов без ошибок JS), обход, xslt-golden (разница — поле поиска
в шапке и страница search), install/migration/fresh-check.
