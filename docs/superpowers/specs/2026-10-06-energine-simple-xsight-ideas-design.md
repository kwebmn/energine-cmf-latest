# Energine Simple — идеи xsight для владельца: дизайн

Дата: 2026-10-06. Статус: утверждено пользователем («ок» на рекомендацию: начать с пунктов 1, 3, 5, 6 разбора).

## 1. Откуда

Разбор xsight 2026-10-06 (`/var/www/clients/client1/web94/private/xsight-dev`, три агента: админка владельца,
разработка и эксплуатация, публичный сайт; спорные пункты сверены с кодом Energine Simple). xsight беднее, чем
казалось: модулей рассылок, статистики и кэша страниц в снимке нет, форм обратной связи, галерей, копирования страниц и
корзины — тоже; берутся идеи, не код (2006–2008 годы, таблицы, md5, ошибки с кодом 200).

## 2. Этап (один, инлайн, свой план)

1. **Битые ссылки на самой странице.** Ссылка из текстового блока на несуществующую страницу сайта или отсутствующий
   файл: гостю — обычный текст (без перехода на 404), отсутствующая картинка не выводится; администратору с правом
   правки вне режима правки — ссылка с пометкой и подсказкой-причиной; в режиме правки текст не меняется (редактор
   сохранил бы изменения). Рабочими считаются: страницы, видимые посетителю, старые адреса (301), ссылки на другой язык
   (не проверяются), внешние, якоря, `mailto:`/`tel:`.
2. **Используемый файл не удаляется молча.** Удаление файла из репозитория, на который ссылается текст страницы
   (любой вид адреса, в том числе через ресайзер; папка — с файлами внутри), — вопрос со списком страниц; повтор с
   подтверждением удаляет. Как у страниц (этап надёжности 1).
3. **Шаблон по умолчанию для подстраниц.** Новая страница раздела — с шаблонами, которые чаще всего у её будущих
   соседей; раздел без подстраниц — текстовая страница. Под списком шаблонов страницы — подсказка, что это за шаблон.
4. **Переключатель языка без 404.** Страница выключена на другом языке (она или её родитель) или это страница
   ошибки — переключатель ведёт на главную того языка.
5. **Страница-ссылка.** У поля «адрес переадресации» формы раздела — выбор страницы из дерева и файла из
   репозитория; пункт меню на внешний адрес открывается в новой вкладке (`target="_blank" rel="noopener"`).

Отложено (решение пользователя): страницы для клиентов (приглашение войти вместо 404, файлы для вошедших), блок
«Другие страницы раздела», черновик страницы, мелочи разработчика (время компонентов в `?debug`, плашка ошибок JS,
стили таблиц), роль со сроком. Не из xsight, но заметный пробел: Open Graph, canonical, hreflang, schema.org.

Не берём: файлы в базе, схемы статусов и согласования, несколько родителей у страницы, свой поиск, cron-скрипты и
`postinstall.sh` xsight, вход и сессии xsight, ошибки с кодом 200, кэш целых страниц (спецификация надёжности его
исключает), манифесты модулей.
