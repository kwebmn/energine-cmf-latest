# Energine Simple — удобство, этап 3: удобство владельца. Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (инлайн). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Владелец видит битые ссылки в своих текстах и получает подсказку «?» на экранах админки.

**Architecture:**
- **Проверка ссылок — класс `Energine\share\gears\LinkChecker`.**
  - Читает `href`/`src` из текстов блоков (`share_textblocks_translation.tb_content`) и описаний разделов (`share_sitemap_translation.smap_description_rtf`).
  - Внешние (`http(s)://` другого хоста), `mailto:`, `tel:`, `#…`, `javascript:` не проверяет.
  - Свой хост или относительный путь: снимает корень сайта и префикс языка, затем ищет раздел по цепочке сегментов (`share_sitemap`) или файл в `web/` (`uploads/…`, `images/…`). Не нашлось — битая ссылка.
  - Результат — строки: раздел, где текст; язык; ссылка; причина.
- **`setup checklinks`** печатает битые ссылки, выход 1, если они есть.
- **Страница админки «Битые ссылки»** (`/admin/links/`):
  - компонент `BrokenLinks` и шаблон `broken_links.content.xml`;
  - таблица: страница (ссылка на неё), язык, ссылка, причина;
  - пусто — «Битых ссылок нет».
  - Раздел и права (только администраторы) добавляет переход `sql/cut/stage13.sql`; генератор кладёт его в базовые данные.
- **Подсказка «?».**
  - Если у компонента в текущем состоянии есть константа `HELP_<КЛАСС>_<СОСТОЯНИЕ>` (например `HELP_DIVISIONEDITOR_EDIT`), компонент выводит свойство `help` с её текстом.
  - `form.xslt`/`list.xslt` показывают в верхней панели `<details class="e-help">`: кнопка «?» с доступным именем, под ней текст.
  - Тексты (ru, ua) — в `stage13.sql` для экранов: раздел (правка, добавление), пользователи (грид, форма), файлы, переводы, настройки сайта, шаблоны писем (форма), битые ссылки.
- **«Новая страница из шаблона с примером текста»** уже есть: пустые секции показывают образец (подпроект UI2). Отдельной работы нет — решение в журнал.

**Tech Stack:** PHP 8.5, XSLT, MariaDB, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-05-energine-simple-convenience-design.md` (этап 3).

## Global Constraints

- Внешние сайты не запрашиваются.
- Страница «Битые ссылки» доступна только администраторам.
- Подсказка не мешает существующим экранам: та же раскладка панели, нет горизонтальной прокрутки (`admin.js`).
- Общие правила:
  - конфиги веб-сервера не трогаются;
  - владелец `web97:client1`;
  - пароли не в git и не в выводе;
  - письма только локально;
  - web93 только читается;
  - `rebuild.sh` не запускается;
  - база меняется только `stage13.sql`.

## Review Focus

1. **Ссылки** с `?query`, `#якорем`, без завершающего `/`, с языком (`ua/…`), абсолютные на свой домен, `../`, кодированные символы: нет ложных «битых».
2. **Ссылка на отключённую или скрытую от гостя страницу** — отмечается («страница недоступна гостю»), а не пропускается молча.
3. **Большой текст и много страниц:** проверка за один проход по таблице сегментов, без запроса на каждую ссылку.
4. **Гость и посетитель без прав** на `/admin/links/` — отказ, как у прочих страниц админки.
5. **«?» и Jodit/формы:** `details` не перехватывает Enter в полях формы; доступное имя у кнопки.

Проверки: п. 1–3 — `tests/links.php`; п. 4 — `tests/links.php` и `smoke-rights`; п. 5 — `admin.js`.
