# Energine Simple — этап 5б: почта через SMTP. Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Письма сайта уходят через `mail()` по умолчанию или через SMTP-сервер, если он задан в конфиге. Клиент SMTP — свой, около 200 строк: SSL или STARTTLS, AUTH LOGIN и PLAIN. Сторонних библиотек нет.

**Architecture:**
- **Конфиг** `mail.smtp`: `host`, `port`, `encryption` (`ssl` — TLS сразу, `tls` — STARTTLS, пусто — без шифрования), `username`, `password`, `timeout`, `cafile` (свой центр сертификации, например самоподписанный сервер). Нет `host` — `mail()`, как сейчас. В шаблоне конфига блок описан закомментированным.
- **`Mail`** собирает письмо один раз: заголовки и тело MIME, как сейчас. Для SMTP к ним добавляются `To`, `Subject`, `Date`, `Message-ID`. Адреса без переводов строки — проверка до отправки любым способом, чтобы нельзя было подставить заголовок или команду SMTP.
- **`Energine\share\gears\SmtpTransport`** — `send($from, array $to, $message)`:
  1. соединение `ssl://` или `tcp://` с таймаутом, приветствие 220;
  2. `EHLO` (имя — `site.domain`), для `tls` — `STARTTLS` и снова `EHLO`;
  3. при `username` — `AUTH PLAIN`, если сервер его предлагает, иначе `AUTH LOGIN`;
  4. `MAIL FROM`, `RCPT TO` на каждого получателя, `DATA`, тело с CRLF и удвоением точки в начале строки, `.`, `QUIT`.

  Сертификат сервера проверяется: `verify_peer`, имя хоста, `cafile` по желанию. Любой неожиданный ответ — `SystemException` с кодом и текстом ответа сервера. Пароль в сообщение не попадает.
- **Тесты.**
  - `tests/tools/fake-smtp.php` — поддельный сервер: одно соединение на 127.0.0.1, режимы `plain`, `starttls`, `ssl`, предлагаемые способы AUTH, отказ в AUTH. Пишет разговор и письмо в файл. Для TLS тест создаёт самоподписанный сертификат `openssl` во временной папке.
  - `tests/smoke-smtp.php`: письмо через `Mail` с конфигом, подменённым в памяти (`Primitive::setConfig`, конфиг площадки не трогается), против поддельного сервера во всех режимах, затем против настоящего postfix на `localhost:25` с доставкой в локальный ящик.

**Tech Stack:** PHP 8.5 (streams, openssl), postfix этой машины, bash.

**Spec:** `docs/superpowers/specs/2026-09-26-energine-simple-design.md` — раздел 4 «Почта в ядре», раздел 7.

## Global Constraints

Те же, что на этапах 1–5а:
- конфиги веб-сервера и почтового сервера не трогаются;
- владелец файлов `web97:client1`, git от root, после него `chown`;
- PHP — `php8.5`;
- пароли не попадают ни в git, ни в вывод команд;
- **письма — только на `web97@loki.kweb.biz`**; поддельный сервер наружу ничего не отправляет;
- `rebuild.sh` не запускается, сверка установки — `fresh-check.sh`;
- после правки PHP перед проверкой — пауза: opcache PHP-FPM видит изменения не сразу.

Особое: конфиг площадки не меняется, у simple.energine.org почта по-прежнему идёт через `mail()`. SMTP включается конфигом, в тестах — в памяти процесса.

## Review Focus

1. **Письмо, пришедшее через SMTP, такое же, как через `mail()`:** тема и имена в UTF-8, текст и HTML, вложения, строки из точки. Тест — `smoke-smtp.php`, сравнение принятого письма.
2. **Ошибки SMTP понятны и не теряются.** Недоступный сервер, отказ в AUTH, отказ в получателе — исключение с ответом сервера. Страницы сайта показывают его, как ошибку `mail()` сейчас. Пароль нигде не виден.
3. **STARTTLS не выполняется молча без шифрования.** Если сервер не предлагает STARTTLS при `encryption=tls` — отказ, а не отправка открытым текстом. Сертификат проверяется.
4. **Подстановка заголовков и команд:** CR/LF в адресе, теме или имени отправителя не создаёт новый заголовок и не превращается в команду SMTP.
5. **По умолчанию ничего не меняется:** без `mail.smtp` письма идут через `mail()`, регрессия и почтовый набор зелёные.

### Task 1: Поддельный сервер SMTP и тест (красный)

- [ ] `tests/tools/fake-smtp.php`: `php8.5 fake-smtp.php <порт-файл> <журнал> <режим> [auth=PLAIN,LOGIN] [password]`. Слушает `127.0.0.1:0`, пишет выбранный порт в файл, принимает одно соединение, отвечает по протоколу, пишет разговор и тело DATA в журнал, завершается после `QUIT` или по таймауту.
- [ ] `tests/smoke-smtp.php`:
  - самоподписанный сертификат во временной папке;
  - сервер в фоне для каждого случая;
  - `Mail` с конфигом в памяти.

  Случаи:
  - без шифрования и AUTH — письмо принято целиком: заголовки, тема UTF-8, текст и HTML, строка «.» удвоена в разговоре и восстановлена в письме, два получателя;
  - STARTTLS + AUTH LOGIN (сервер предлагает только LOGIN);
  - SSL + AUTH PLAIN;
  - неверный пароль — исключение с ответом сервера, пароля в тексте нет;
  - порт без сервера — исключение;
  - сервер без STARTTLS при `encryption=tls` — отказ, в журнале нет `MAIL FROM`;
  - CR/LF в адресе получателя — отказ до соединения, у `mail()` тоже;
  - настоящий postfix `localhost:25` — письмо доходит в локальный ящик.
- [ ] Красный прогон: `SmtpTransport` нет. Коммит тестов.
