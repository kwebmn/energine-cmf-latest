# Energine Simple — удобство, этап 4: конфиги компонентов без копий. Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (инлайн). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Конфиг компонента хранит только отличия от базового: `<configuration extends="FileRepository.component.xml">`. Копии конфигов (`FileRepositoryModal`, `FileRepositorySelect`, `SiteDivisionEditor`, `MailTemplateEditor`) становятся короткими.

**Architecture:**
- **`ComponentConfig`.** Если у корня `configuration` есть атрибут `extends`, загружается базовый конфиг — тем же поиском, рекурсивно, с защитой от цикла. Затем состояния объединяются:
  - состояние с тем же `name` заменяется целиком;
  - новые состояния добавляются в конец;
  - `<state name="…" remove="1"/>` убирает состояние базового.
- **Сверка эквивалентности.** Тест `tests/config-extends.php` сравнивает объединённый конфиг каждого переведённого файла с его прежним полным содержимым из git (ревизия до задачи). Состояния сравниваются по имени и канонической форме (`C14N`), порядок не важен.

**Решения этапа (из спецификации, раздел 2, этап 4):**
- **«SQL с параметрами» не делается.** Запросы с данными запроса уже идут через подстановки QAL (`%s` и массивы значений). Прямой вставки `$_GET`/`$_POST` в строку SQL проверка не нашла. Переписывать 107 мест ради формы — риск без выгоды. Решение — в журнал.
- **«Два класса вывода вместо девяти построителей» не делается.** Каждый построитель — отдельная стратегия, их используют гриды, формы, дерево и JSON. Объединение — риск средний при малой выгоде. Решение — в журнал.

**Spec:** `docs/superpowers/specs/2026-10-05-energine-simple-convenience-design.md` (этап 4).

## Global Constraints

- Поведение компонентов не меняется: те же состояния, поля, панели.
- Общие правила проекта: конфиги веб-сервера не трогаются; владелец `web97:client1`; пароли не в git и не в выводе; письма только локально; web93 только читается.

## Review Focus

4. **Конфиги, которые передаются параметром `config`** (путь к файлу), — тоже наследуют.
